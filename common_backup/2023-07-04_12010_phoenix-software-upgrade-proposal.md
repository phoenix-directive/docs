**Terra Core v2.4.0**
On 30 June 2023, Terra upgraded Pisco (Terra’s testnet chain) and incorporated several new and important updates, including:

- Allow amino messages to be used for signing alliance messages. This change allows Ledger to be used with the alliance module.
- Fixed an issue with authz not validating messages when executing Exec transactions.
- Fixed an issue with DonateAllVestingTokensMsg failing when users had dust delegations that couldn’t be undelegated.
- Fixed an issue with ibc-hooks in which callbacks were not triggering smart contracts as expected.


Following testing, this software upgrade proposal will incorporate these updates into Phoenix-1 (mainnet).
This is a consensus-breaking change that requires a SoftwareUpgradeProposal that will be put up for governance voting following this community discussion.
