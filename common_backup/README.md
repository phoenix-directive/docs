## Method & caveats

- **Forum data**: exported via the common.xyz API with `export_common.py` (full post bodies, every comment and reply, images downloaded to `images/`).
- **On-chain data**: all proposals with status `PASSED` from the Terra LCD (`lcd.phoenix-foundation.dev`, `/cosmos/gov/v1/proposals`). Older, never-passed proposals have been pruned from chain state, so only passed/rejected ones remain queryable.
- **Matching**: primarily via the forum link embedded in each on-chain proposal; chain upgrades without links are matched by version number; the rest by title similarity. Spot-check before quoting.
- **USD values**: LUNA amount × Binance LUNA/USDT daily close on the voting-end date. Amounts sent to multisigs or vesting contracts are counted as paid out on that day, even if later released, returned or burned (e.g. the 150M LUNA TFL Community Grant (#4790) was largely burned in 2024 under TFL’s bankruptcy order; LP-deployment spends such as #4736 and #4844 remain community-owned liquidity).
- Summaries were written from each post’s text and are condensed; read the linked file for details.
